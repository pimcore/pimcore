# Content Management Features

Pimcore provides a set of built-in content management capabilities that apply across documents, assets, and data objects.
These features work consistently across element types, giving editors and developers a unified toolset
for managing content lifecycles.

- [Versioning](./01_Versioning.md) - Track changes, compare revisions, and restore previous states of any element
- [Notes & Events](./02_Notes_and_Events.md) - Log changes and events independently from versioning
- [Tags](./03_Tags.md) - Classify and filter elements with custom taxonomies
- [Properties](./04_Properties.md) - Attach custom key-value metadata to elements
- [Scheduling](./05_Scheduling.md) - Automate publish, unpublish, and delete actions on a schedule
- [GDPR Data Extractor](./06_GDPR_Data_Extractor.md) - Search and export personal data across data sources
- [Notifications](./07_Notifications.md) - Send and receive in-app notifications between users and groups
- [Object Data Inheritance](./09_Object_Data_Inheritance_in_Action.md) - Reduce maintenance with hierarchical data inheritance
