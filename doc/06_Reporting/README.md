# Reporting

Pimcore provides reporting tools for querying, visualizing, and exporting data from across the system.
These range from SQL-based tabular reports to interactive dashboards and statistics views.

## Custom Reports

SQL-based tabular and chart reports with filtering, CSV/XLSX export, and extensible data source adapters.
Build reports against any database table or custom data source, configure column visibility,
drill-down filters, and chart visualizations directly in Pimcore Studio.

[Custom Reports Documentation](./01_Custom_Reports.md)

## Statistics Explorer (Enterprise)

Interactive data aggregation, pivot tables, and charting across Pimcore data sources.
Statistics Explorer also integrates as a Custom Report adapter for embedding aggregated views
into the standard reporting interface.

- [Statistics Explorer Documentation](https://github.com/pimcore/statistics-explorer/blob/doc-refactoring/doc/README.md)
- [Custom Report Integration](https://github.com/pimcore/statistics-explorer/blob/doc-refactoring/doc/04_Custom_Report_Integration/README.md)

## Dashboards (Enterprise)

Configurable dashboards with portlets in Pimcore Studio.
Combine reports, charts, and key metrics into personalized dashboard views.

[Dashboards Documentation](https://github.com/pimcore/studio-dashboards-bundle/blob/doc-refactoring/doc/00_Installation.md)
