On class level, there are multiple additional settings and features available which influence the appearance and behaviour of Pimcore. These can be configured in the Pimcore backend or via code by a developer.

#### These features include:

* [Custom Icons for objects](./02_Custom_Icons.md)
* [Data Inheritance and Parent Class](./03_Data_Inheritance_and_Parent_Class/README.md)
* [Interfaces and Traits](./04_Interfaces_and_Traits.md)
* [Link Generator](./05_Link_Generator.md)
* [Locking Fields](./06_Locking_Fields.md)
* [Path Formatter](./07_Path_Formatter.md)
* [Preview Generator](./08_Preview_Generator.md)
* [Object Variants](./09_Object_Variants.md)
* Type Declaration
